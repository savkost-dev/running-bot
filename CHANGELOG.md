## [0.9.5] 2026-05-27 — Надёжность: устранение truncated JSON и systemd timeout

### Исправлено (по анализу логов сервера)
- **Truncated JSON** — `max_tokens` увеличен: fast 3k→8k, smart 6k→12k, deep 8k→16k. Главная причина ошибок `Unterminated string` и `Expecting property name`.
- **Systemd timeout (16:54)** — `ask_groq()` теперь запускается через `run_in_executor`, не блокирует asyncio event loop.
- **4 стратегии fallback-парсинга** вместо 2:
  1. Полный JSON
  2. Обрезка на позиции `garmin_workout` (новая — решает усечение в advice-полях)
  3. Regex-стрип garmin_workout с конца (старая)
  4. Извлечение `recommended_group` + `recommended_pace` по одному (крайний fallback)
- **Retry x2** — при пустом ответе от модели повторная попытка через 3 сек
- **Явный timeout** — fast: 30с, smart: 120с, deep: 180с; при превышении → `"⏱ Модель думает слишком долго"`
- **global_error_handler** — уведомляет пользователя об ошибке вместо молчаливого сбоя
