## Остальные файлы (ключевые функции)

### database.py — 1033 строк
Всё хранение данных: пользователи, токены, профили, кэш атлета, кэш восстановления, анализы анонсов, оценки, уведомления.

### telegram_reader.py — 631 строк
Чтение канала @Dusty_Dumbbells через Telethon. Детектор анонсов (`find_next_workout`, `find_next_long_run`), парсер постов, поиск доп. групп в комментариях.

### zones.py — 157 строк
Расчёт персональных темповых зон по методу Дэниелса. Вход: VO2max или лактатный порог. Выход: зоны easy/marathon/threshold/interval/repetition в сек/км.

### fit_generator.py — 350 строк
Генерация .fit файлов для загрузки в Garmin из JSON тренировки.

### data_normalizer.py — 377 строк
Нормализация данных из разных трекеров в единый формат.

### oauth_server.py — 363 строк
Веб-сервер (порт 8080) для OAuth callback: Strava, Whoop, Polar.
