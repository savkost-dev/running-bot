# Датчики пользователей — обход 18.10.2026

Источник: Garmin `get_activity(...).metadataDTO.sensors` по последним пробежкам из снимка за 14 дней + `get_devices()`; COROS — поля `device`, `hasPodDistance`, `podDistance` в старом API (`raw_service_data.coros`). Новый COROS (MCP, `querySportRecords`) отдаёт текст без устройств и датчиков.

## Как Garmin называет датчики
| manufacturer | тип | что это |
|---|---|---|
| STRYD | STRIDE_SPEED_DISTANCE (+ BIKE_POWER, RUN) | настоящий Stryd (Ольга, Дмитрий, Ионов) |
| пусто | STRIDE_SPEED_DISTANCE | Stryd Антона (manufacturer/sku/serial пустые); у Кирилла и Антона В. — неизвестный датчик шага |
| GARMIN, sku 006-B4130 | HEART_RATE + STRIDE_SPEED_DISTANCE + RUN, один серийник | нагрудник HRM-Pro Plus (Юрий, Карев, Ольга на дорожке) |
| GARMIN, sku 006-B3300 | то же | нагрудник HRM-Pro (Bikk) |
| GARMIN, sku 006-B4607 | BLUETOOTH_LOW_ENERGY | HRM 600 (Мария, Никита) |
| DYNASTREAM | STRIDE_SPEED_DISTANCE | шагомер Garmin (Рагожин) |
| MAGENE / POLAR_ELECTRO / FITCARE | HEART_RATE | сторонние пульсометры |

Правило в разборе (0.50.18): Stryd = STRIDE_SPEED_DISTANCE с manufacturer STRYD или пустым. Всё остальное без GPS — дистанции не доверяем.
